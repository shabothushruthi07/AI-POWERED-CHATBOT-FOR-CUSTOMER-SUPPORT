#2. LITERATURE SURVEY

The development of AI-powered chatbots for customer service has been a growing area of
research and innovation. Various studies, tools, and technologies have contributed to the

2.1 EVOLUTION OF CHATBOTS

Early chatbots like ELIZA (1966) and ALICE (1995) demonstrated rule-based responses
using predefined scripts and pattern matching. These systems, while innovative for their
time, lacked true understanding of language or context. Modern chatbots, powered by
Artificial Intelligence (AI) and Natural Language Processing (NLP), can analyze,
interpret, and respond to user input in a more human-like and intelligent manner.

2.2 NATURAL LANGUAGE PROCESSING (NLP)

NLP plays a crucial role in enabling chatbots to understand user queries. Research in this
field has led to the development of algorithms that convert natural language into machinereadable formats. Techniques such as intent recognition, entity extraction, and sentiment
analysis allow chatbots to comprehend context and deliver relevant responses. Tools like
spaCy, NLTK, and transformers (e.g., BERT, GPT) have significantly improved chatbot
capabilities.

2.3 MACHINE LEARNING IN CHATBOTS

Chatbots powered by Machine Learning (ML) can learn from user interactions and
improve their responses over time. ML models help in predicting user intent and identifying
the most appropriate replies. Supervised and unsupervised learning approaches, including
decision trees, neural networks, and deep learning, are widely used in training chatbots for various industries

#6.IMPLEMENTATION

The implementation of the AI-powered customer support chatbot, CogniChat, is a
comprehensive, full-stack project that integrates multiple modern technologies to deliver a
responsive, intelligent, and user-personalized support experience. The application is built primarily
using Python and the Streamlit framework, which allows the creation of interactive web-based user
interfaces directly in Python. The interface includes elements such as user login/signup forms, chat
input areas, notification panels, preference selectors, file upload capabilities, and chat history viewers
— all rendered dynamically using Streamlit’s built-in components. Upon launching the app, users are
prompted to either register or log in. Registration creates a unique user profile stored in a MongoDB
collection, which includes credentials (secured via SHA-256 hashing), language preferences, tone
settings, formatting style (paragraph or bullet), detail level, and timestamps for tracking activity.
Once authenticated, users can interact with the chatbot by entering queries in the chat interface. The
app supports not just plain text input but also file uploads (PDFs), whose contents are extracted using
the PyPDF2 library and appended to the user’s query for better contextual responses. The backend
leverages OpenRouter’s AI API, specifically the deepseek-r1-distill-qwen-32b model, to
generate intelligent responses. Each message sent by the user is wrapped with context including
recent chat history, preferences, optional file content, and a dynamically calculated focus score—a
custom metric derived through a heuristic multi-scale attention mechanism. This score adjusts based
on query length, specificity, and emotional or directive tone, helping prioritize or shape AI responses
more meaningfully.
A unique feature of this chatbot is its proactive intelligence. The app periodically analyzes user
behavior, past interactions, and frequently used keywords to detect interests and generate timely
suggestions or conversation starters. Additionally, it uses the Google Custom Search API to retrieve
relevant external information, which can be embedded in the query context if no file is uploaded. To
ensure a smooth conversational experience, the chatbot monitors for keywords such as "agent,"
"human," or "representative" — and if detected, the system escalates the request by presenting a
placeholder message indicating that a human agent will be contacted.
On the backend, all queries and AI responses are stored in a MongoDB collection, capped by a
MAX_CHAT_HISTORY threshold to manage database size. Chat entries also include optional user ratings,
which contribute to analytics displayed in the dashboard — such as average feedback score and top
user interests. These analytics are visualized through Streamlit’s expandable widgets and offer both
the users and developers insights into interaction trends and engagement levels. Furthermore, the app
includes a robust user preferences management system, allowing individuals to set and update their
interaction style and language through dropdown menus. Preferences are fetched and saved
dynamically in the user profile and are always included in every AI request to ensure consistency in
the response tone and formatting.
The chatbot operates asynchronously using Python’s asyncio module to handle real-time
communication and avoid interface blocking, especially during API calls to external services. Error
handling is gracefully managed with detailed feedback messages in the interface, allowing users to
understand issues like API errors, invalid credentials, or unsupported file formats. Notifications and
proactive suggestions are displayed in the sidebar and managed through Streamlit’s session state.
Finally, the app is structured in a modular way, separating concerns across functions like user
authentication, chat management, AI query handling, PDF parsing, interest detection, and analytics
reporting, which makes the codebase maintainable and scalable. The chatbot can be deployed on
cloud platforms like Render, Heroku, or AWS, with environment variables safely stored for
sensitive data like API keys and database credentials.

 NLU (Natural Language Understanding) Testing

NLU testing focuses on the chatbot's ability to understand and interpret user input accurately
especially the intent and relevant entities. This type of testing ensures that when users express
themselves in various ways — such as saying "I want to cancel my order" or "Can I get a
refund?" — the chatbot consistently recognizes the underlying intent as a cancellation request.
Likewise, it tests whether the bot can extract important details like product names, order
numbers, or dates from user messages. This testing often involves labeled datasets and confusion
matrix analysis to evaluate precision and recall. Tools like Rasa offer dedicated NLU testing
commands to automate this process. Effective NLU testing is critical for maintaining chatbot
accuracy, user trust, and seamless task completion

CONVERSATION FLOW TESTING

Conversation flow testing assesses how well the chatbot handles multi-turn interactions —
that is, conversations that span several messages. It checks whether the bot maintains context,
responds logically based on previous inputs, and follows predefined conversation paths. For
instance, if a user says they want to return a product, the bot should ask for the order number,
process the input, and confirm the action appropriately. If a user changes the topic midconversation, the bot should either adapt or handle the switch gracefully. This testing can be
done manually using predefined scenarios or through automated story testing tools in platforms
like Rasa. Well-executed conversation flow testing ensures that the chatbot feels natural, avoids
getting stuck, and offers a coherent user experience.

USER ACCEPTANCE TESTING(UAT)

User Acceptance Testing (UAT) is the final validation step where real users or business
stakeholders interact with the chatbot to ensure it meets practical requirements and business
goals. During UAT, testers simulate real-life use cases like asking for a refund, checking
order status, or reporting a problem, and provide feedback on how well the bot performs.
This testing focuses not only on functionality but also on the overall user experience,
including tone, accuracy, clarity, and responsiveness. Insights gained from UAT help
identify usability issues, conversation gaps, and unexpected user behaviors that technical
testing might overlook. The feedback collected is essential for refining the chatbot before
launch and prioritizing future improvements.
